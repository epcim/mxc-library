Decoupled Portfolio

Standard Workload Composition Library

The companion workload catalog for the MXC ecosystem. Fully decoupled, OCI-ready, and independently versioned schemas supplying production system planes and application templates.

Explore Stacks Core Compiler Docs

Eco-System Alignment

"Compile with the Engine. Deploy with the Catalog."

While the core MXC Compiler Engine defines compile-time validation rules and projections, this workload library provides the actual, operational portfolio of Kubernetes system planes. Together, they provide dry-run safety and a DRY codebase.

Library Capabilities

Designed to structure robust enterprise portfolios, providing clean boundaries between developers and platform runtimes.

🔌

Delegated Projections

Per Rule 1, all active projection logic delegates to the core mxc engine. This guarantees zero duplicate codes, preventing compile drift.

🏛️

Multi-Library Mixing

Built on CUE unification, you can easily combine, extend, and override standard stacks with your own custom, private organization stack portfolios.

📦

OCI Portability

Our adapters use 100% flat static paths with no parent directory traversals, ensuring stacks package cleanly into OCI image registries.

🛡️

Centralized Stack Defaults

Common configs, resource sizes, and annotations are centralized directly inside stack defaults, keeping cluster environment files brief and elegant.

🎯

Clean Modular Subdirs

Complex application stacks utilize optional subdirectories separating core schemas from auxiliary native CUE overlays (zero Jinja interpolation).

📦

OCI Package Distribution

Published as a standalone OCI artifact, so cluster configs can pin and consume library versions directly — no cross-repo tooling needed.

Quick Start & Development

Run validation and parameters exports directly from the mxc-library/ catalog scope.

# 1. Validate all library schemas and workload values against constraints just -f ../justfile -d .. mxc::validate # 2. Compile and output flat parameters (vars.yml) to stdout to inspect just -f ../justfile -d .. mxc::export # 3. Export compiled values and save them directly for Kluctl deployment just -f ../justfile -d .. mxc::export > ../cluster-home-mxc/vars.yml
